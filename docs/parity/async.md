# Async parity matrix

| SQLAlchemy feature | Status | Proving test | Notes |
| --- | --- | --- | --- |
| `create_async_engine`, checkout, and async context managers | partial | `tests/test_async_engine.py::test_async_connect_supports_await_and_async_context_manager`, `test_async_memory_database_is_shared_between_checkouts`, `test_async_file_database_and_lifecycle_errors` | Tokio-backed SQLite skeleton; memory and file URLs plus synchronous-engine pool options are accepted. `:memory:` checkouts serialize through one shared SQLite handle, and transactions opened through one async wrapper are visible to siblings, and only a holder with its own transaction can end the shared wire (fresh-holder operations are no-ops), matching SQLAlchemy SQLite `:memory:` default pool semantics. `connect()` is awaitable and supports `async with`. No async session, cancellation guarantees, or cross-dialect support. Since `aiosqlite` is not installed in `.venv`, parity is compared against sync SQLAlchemy SQLite semantics, not an async SQLAlchemy driver. |
| Buffered async statement execution and named binds | partial | `tests/test_async_engine.py::test_async_select_insert_and_ddl_match_sync_sqlalchemy`, `test_async_text_named_binds_and_transactions` | SELECT/INSERT/DDL and `text()` named mappings execute through Tokio blocking tasks, returning shared synchronous `CursorResult` because results are natively buffered; fetching does not require async awaits. No streaming or ORM async APIs. Compared against sync SQLAlchemy SQLite semantics because `aiosqlite` is unavailable. |
| Async commit, rollback, begin, close, and dispose | partial | `tests/test_async_engine.py::test_async_text_named_binds_and_transactions`, `test_async_begin_rolls_back_on_exception`, `test_async_file_database_and_lifecycle_errors` | Transaction operations and checkout/disposal use Tokio `spawn_blocking`; pool reset-on-return is shared with sync. The `:memory:` singleton shares transaction state across checkouts; only holders with their own transaction end the shared wire, while file checkouts remain independent. Cancellation and concurrent-query behavior are not claimed or tested. AsyncSession remains not started. |
