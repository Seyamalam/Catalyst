# Dialect parity matrix

| SQLAlchemy feature | Status | Proving test | Notes |
| --- | --- | --- | --- |
| SQLite positional text execution | partial | `tests/test_sqlite_text.py` | A foundation helper uses rusqlite; no dialect compiler or engine/pool API exists. |
| PostgreSQL async text execution | partial | `tests/test_postgres.py::test_postgres_named_text_select_dml_and_transactions` | Tokio-native single connection; named `:bind` parameters, buffered primitive SELECT results, DML rowcount, and basic transactions. No pool; compiled Core statements cannot execute yet (text SQL only); no ORM, savepoints, executemany, streaming, or broad type support. Real test requires `CATALYST_POSTGRES_URL`; text exceptions redact driver messages. TLS verification is default; local plaintext requires explicit `sslmode=disable`. |
| PostgreSQL dialect compilation (Core and DDL) | partial | `tests/test_postgres_dialect.py` | Rust renders PostgreSQL SQL for select/insert/update/delete and CREATE/DROP TABLE via `compile(dialect="postgresql")`: `$N` positional placeholders (parity tests normalize SQLAlchemy's `%(name)s` pyformat binds by first appearance), typed bind casts (`::INTEGER`, `::VARCHAR`, `::TIMESTAMP WITHOUT TIME ZONE`, `::DATE`) and inferred casts for untyped binds, inline `true`/`false` boolean literals, `||` string concatenation, `CAST(... AS NUMERIC/FLOAT)` true division, SQLAlchemy's empty-IN/NOT-IN forms, `LIMIT ALL OFFSET` pagination, SERIAL single-integer primary keys, PostgreSQL type names, and reserved-word/identifier quoting. Compilation is dialect-scoped in the plan cache; unknown dialects raise `ArgumentError`. Execution of compiled statements over the PostgreSQL connection is not implemented (text SQL only); no joins, aliases, CTEs, RETURNING, schemas, executemany, or broad type support. |
| MySQL dialect and execution | not started | — | Driver selected in [ADR 0004](../decisions/0004-mysql-driver.md); no driver code or SQLAlchemy parity test exists. |
| Docker integration harness: plaintext service protocol probes | partial | `tests/test_integration_infra.py::test_postgres_plaintext_startup_response`; `tests/test_integration_infra.py::test_mysql_plaintext_protocol_greeting` | Harness-infrastructure coverage only: checks TCP and initial protocol framing with TLS disabled. Real PostgreSQL SQL execution is proven separately by `tests/test_postgres.py`; no PostgreSQL TLS-enabled server or SQLAlchemy cross-driver parity test is included. |
